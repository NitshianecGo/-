# NovaChat

Красивый статический Telegram-style веб-клиент без backend.

## Запуск
Откройте `index.html` в браузере.

## GitHub Pages
Загрузите файлы в репозиторий GitHub. В Settings → Pages выберите Deploy from a branch → `main` → `/ (root)` → Save.

## Что внутри
- адаптивный desktop/mobile интерфейс
- список чатов и поиск
- избранное
- плавные анимации
- responsive mobile drawer
- настройки
- отправка сообщений по Enter
- сохранение истории в localStorage
- имитация ответа собеседника
- никаких npm/node зависимостей
