# ✦ Azeroth Pulse — инструкция на русском

Новостной сайт о World of Warcraft в стиле тёмного фэнтези с золотыми акцентами и персонажем-разведчиком Riko из визуальной вселенной Little Azeroth Friends.

## Что уже есть в проекте

- Лента публикаций за последние 5 дней: Blizzard, Wowhead, MMO-Champion, Google News, YouTube и Reddit.
- Автоматическая группировка похожих заголовков и список источников у каждой темы.
- Индекс хайпа 0–100. Это расчётная оценка по свежести, числу источников и публичным сигналам Reddit, а не реальные просмотры.
- Отдельные метки подтверждённых официальных публикаций, новостей СМИ и неподтверждённых слухов / утечек.
- Русские ИИ-сводки и объяснение «Почему важно» — необязательная функция, которая включается API-ключом. Без ключа сайт остаётся рабочим, показывая исходные выдержки.
- Категории, поиск, сортировка, фильтры Retail / Classic / Hardcore / PvP / лор.
- Избранное на текущем устройстве, переключение RU/EN, встроенное окно YouTube.
- Копирование ссылки, отправка в Telegram, системное меню «Поделиться», скачивание карточки новости PNG.
- Календарная подборка событий, PWA-установка и кэш оболочки сайта для открытия без сети.
- Автоматический ежедневный Telegram-дайджест и отдельный интерактивный Telegram-бот.

## Публикация на GitHub Pages

В текущем репозитории используется режим GitHub Pages **Deploy from a branch**: ветка `main`, папка `/(root)`. Оставь этот источник включённым. Файлы сайта находятся в корне, а Pages автоматически пересобирает его после изменений в ветке.

1. Оставь `index.html`, `styles.css`, `app.js`, `data/news.json` и папку `assets/` в корне репозитория.
2. Не удаляй `.github/workflows/`: там находятся автоматизации.
3. Чтобы загрузить свежие новости прямо сейчас, открой **Actions → Refresh WoW news feed → Run workflow**.
4. Сборщик запускается каждые четыре часа (`17 */4 * * *`, UTC), обновляет `data/news.json` и отправляет коммит. GitHub Pages затем автоматически пересобирает сайт из ветки.
5. Адрес публикации отображается в `Settings → Pages`. Обычно для этого репозитория он выглядит как `https://NitshianecGo.github.io/-/`.

Если планировщик GitHub Actions задерживается, запускай сборщик вручную на вкладке Actions. Если Actions отключены, включи их в `Settings → Actions → General`. Если источники временно недоступны, сборщик сохраняет последнюю свежую ленту; при полном сбое первого запуска он выдаёт ошибку, а не подменяет её пустой лентой.

## Включить ИИ-сводки (необязательно)

1. Создай API-ключ в настройках OpenAI API. Использование API может стоить денег; GitHub Pages и обычный сборщик без ключа работают бесплатно.
2. В репозитории открой `Settings → Secrets and variables → Actions → New repository secret`.
3. Имя секрета: `OPENAI_API_KEY`. Значение: твой ключ. **Не вставляй его в HTML/JS и не публикуй в репозитории.**
4. По умолчанию используется модель `gpt-4.1-mini`; при необходимости модель можно переопределить переменной Actions `OPENAI_MODEL`.
5. Сейчас запрашивается до 18 сводок за один запуск. Это регулируется переменной `AI_MAX_ITEMS` в `.github/workflows/update-news.yml`.

Сводки — помощник для быстрого чтения, а не первоисточник. Важные факты проверяй в оригинальной статье.

## Настроить ежедневный Telegram-дайджест (необязательно)

1. В Telegram открой `@BotFather`, создай бота командой `/newbot` и скопируй токен.
2. Напиши новому боту `/start`. Узнать свой числовой ID можно через `@userinfobot`. Для канала добавь бота в администраторы с правом публиковать сообщения.
3. В репозитории создай два секрета в `Settings → Secrets and variables → Actions`:
   - `TELEGRAM_BOT_TOKEN` — токен бота;
   - `TELEGRAM_CHAT_ID` — твой числовой ID или ID канала.
4. (Необязательно) Добавь переменную Actions `AZEROTH_SITE_URL` с адресом опубликованного сайта.
5. Открой `Actions → Telegram daily digest → Run workflow`, чтобы отправить тестовую подборку. Потом дайджест будет отправляться каждый день в 09:00 UTC (18:00 в Корее).

Если секреты не заданы, workflow аккуратно пропускает отправку. Токен не нужно хранить в публичном файле.

## Интерактивный Telegram-бот с командами

Это не то же самое, что запланированный дайджест. Чтобы бот отвечал на `/latest`, `/top` и `/digest`, его процесс должен постоянно работать на компьютере или сервере. Сам GitHub Pages этого не делает.

**Windows PowerShell:**

```powershell
$env:TELEGRAM_BOT_TOKEN="ТВОЙ_ТОКЕН"
$env:AZEROTH_NEWS_URL="https://ТВОЙ-ЛОГИН.github.io/azeroth-pulse/data/news.json"
python scripts/telegram_bot.py
```

**macOS / Linux:**

```bash
export TELEGRAM_BOT_TOKEN="ТВОЙ_ТОКЕН"
export AZEROTH_NEWS_URL="https://ТВОЙ-ЛОГИН.github.io/azeroth-pulse/data/news.json"
python3 scripts/telegram_bot.py
```

Команды: `/start`, `/latest`, `/top`, `/digest`, `/help`. Остановишь программу или выключишь компьютер — интерактивный бот перестанет отвечать. Для постоянной работы нужен включённый компьютер или хостинг с постоянно работающим процессом.

## Что важно знать

- Новости собираются из общедоступных лент. RSS/API могут менять формат, ограничивать запросы или временно не отвечать; причины ошибок видны в логах `Actions`.
- Некоторые статьи не содержат картинки, краткого описания или точной даты события. Сайт не выдумывает изображения и даты, если их нет в данных.
- Google News используется как агрегатор публикаций, а не как показатель вовлечённости. Для хайпа берутся доступные сигналы; просмотры YouTube не придумываются.
- Избранное хранится только в текущем браузере и не синхронизируется между устройствами.
- Офлайн-кэш позволяет открыть оболочку сайта; свежая лента требует интернета.
- Это фан-проект, не связанный с Blizzard Entertainment. Статьи и изображения принадлежат их владельцам; сайт ведёт к первоисточникам.
